# 决策落点对照（方案 §8 ADR）

方案 §8 用 11 条 ADR 记下"为什么这样设计"。设计决策最容易发生的事是**代码长歪了但决策文本
没改**，所以这张表把每条 ADR 对到今天代码里的落点，并由 `tools/verify_plan_traceability.py
--decisions` 机器核对：

1. §8 的每个 `ADR-*` 编号必须且只能出现一次；
2. 状态只能取 `已落实` / `部分落实` / `偏离并说明` / `未落实`；
3. 引用的反引号路径与行号必须真实存在；
4. 后三种状态必须写清偏在哪里、为什么。
