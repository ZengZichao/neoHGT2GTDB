# 验收标准对照（方案 §1.4 DoD 与 §10.7 checklist）

方案 §1.4 给了 10 条成功标准（DoD-0…DoD-9，DoD-0 只出现在 §10.7 的 checklist 里），
§10.7 又把它们列成未勾选的复选框。这份文件替代"口头说达标"：每条给状态、证据与
（若非"达标"）缺的那一块，并由 `tools/verify_plan_traceability.py --acceptance` 机器核对：

1. §1.4 表格与 §10.7 checklist 里出现的每个 `DoD-*` 必须且只能在下面这张表出现一次；
2. 状态只能取 `达标` / `部分达标` / `被外部条件阻塞`；
3. 引用的反引号路径与行号必须真实存在；
4. 非"达标"必须写清缺哪一块、被什么挡住。

## 与 §10.7 checklist 的关系

§10.7 是同一批标准的复选框版本，本表逐条覆盖它的全部 `DoD-*` 行；方案文档本身保持只读，
勾选由本表 + 门禁承担——任何一条的证据路径失效或状态词写错，`tools/verify_plan_traceability.py`
就会 FAIL 并指名是哪一条。
