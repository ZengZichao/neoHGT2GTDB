# 风险应对登记（方案 §9 风险登记册）

方案 §9 列了 19 条风险（RK1–RK19），每条给的是**计划中的缓解**。这份登记回答的是
"实现到最后，这条缓解到底在不在"，并被 `tools/verify_plan_traceability.py --risks` 机器核对：

1. §9 的每个 `RK*` 编号必须且只能出现一次；
2. 状态只能取 `已实现缓解` / `部分实现` / `登记接受`；
3. 引用的反引号路径与行号必须真实存在；
4. `部分实现`/`登记接受` 必须写清缺的是哪一块、为什么。
