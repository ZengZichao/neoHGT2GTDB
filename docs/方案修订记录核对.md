# 方案 §0.5 审查修订记录核对（REV-01…REV-19）

§0.5 是方案在 2026-11-02 依据**本地只读 r220 副本**做的 19 条修订：每条写下"原假设 →
本地实测 → 哪些章节因此改动"。它们决定了整份设计的基线，所以也必须逐条核对：今天代码与文档
到底采纳了没有。规则与其他登记表一致：状态取 `已采纳` / `部分采纳` / `未采纳`，非"已采纳"
必须写清缺的是哪一块，引用路径与 `::符号` 必须可解析。
