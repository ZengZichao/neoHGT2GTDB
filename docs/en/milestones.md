# Plan §13 milestone check (M0–M7)

§13 is the plan's own "how far along" view: each row writes what is to be delivered within the week and which passing test is the criterion. Registering it
has two uses: first, it makes the completion of "the six stages + enhancement items" machine-checkable (the same rule set as the other registers); second, it
**puts the still-unfinished scope in plain sight** instead of mixing it into the body text. Status takes `已达成` / `部分达成` / `未达成`;
anything not `已达成` must state clearly which piece is missing.
