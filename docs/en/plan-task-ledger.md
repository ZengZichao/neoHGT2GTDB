# Plan §6 tasks ↔ implementation ledger

This table maps the **numbered tasks** in plan document §6 "phased implementation plan" (S0–S3, 2.1–2.13, 3.1–3.6,
4.1–4.5, 28 items in total) one by one onto implementation locations and evidence. Its reason for existing is the same as `tools/verify_plan_traceability.py`'s:
"already completed" written in prose cannot be machine-checked, and actual sweeps have turned up several instances of "written in the plan with no corresponding implementation in the code"
or "the option parses but nobody reads it".

Check rules (executed by `python tools/verify_plan_traceability.py --ledger docs/计划任务对照表.md ...`;
failing any one of them is a FAIL):

1. Every ID in the §6 table must appear exactly once in this table, and none may appear out of thin air.
2. The status may only take `已实现` / `部分实现` / `未做`.
3. File paths written in backticks in the implementation locations of `已实现`/`部分实现` rows must **really exist**.
4. `部分实现`/`未做` rows must state clearly in the last column which part is missing (leaving it blank and glossing over is not allowed).

The unnumbered phase entries (P1's three-task list and the P5/P6/P7 prose entries of §6.7) are covered in the "unnumbered entries" section
at the end of this file and do not take part in the ID check.
