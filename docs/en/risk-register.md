# Risk-mitigation register (Plan §9 risk register)

Plan §9 lists 19 risks (RK1–RK19), each given as a **planned mitigation**. This register answers
"once the implementation is carried through to the end, is this mitigation actually there", and is machine-checked by `tools/verify_plan_traceability.py --risks`:

1. Every `RK*` number of §9 must appear exactly once;
2. Status may only take `已实现缓解` / `部分实现` / `登记接受`;
3. The referenced backtick paths and line numbers must really exist;
4. `部分实现`/`登记接受` entries must state clearly which piece is missing and why.
