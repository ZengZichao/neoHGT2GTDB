# Decision-implementation check (Plan §8 ADR)

Plan §8 uses 11 ADRs to record "why it was designed this way". The thing most likely to happen to a design decision is **the code drifting while the decision text
stays unchanged**, so this table maps each ADR to where it lands in today's code, and it is machine-checked by `tools/verify_plan_traceability.py
--decisions`:

1. Every `ADR-*` number of §8 must appear exactly once;
2. Status may only take `已落实` / `部分落实` / `偏离并说明` / `未落实`;
3. The referenced backtick paths and line numbers must really exist;
4. The last three statuses must state clearly where the deviation is and why.
