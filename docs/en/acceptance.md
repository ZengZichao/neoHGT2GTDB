# Acceptance-criteria check (Plan §1.4 DoD and §10.7 checklist)

Plan §1.4 gives 10 success criteria (DoD-0…DoD-9, with DoD-0 appearing only in the §10.7 checklist),
and §10.7 lists them in turn as unchecked checkboxes. This document replaces "saying verbally that they are met": each item is given a status, evidence, and
(if not "met") the piece that is missing, and is machine-checked by `tools/verify_plan_traceability.py --acceptance`:

1. Every `DoD-*` appearing in the §1.4 table and the §10.7 checklist must appear exactly once in the table below;
2. Status may only take `达标` / `部分达标` / `被外部条件阻塞`;
3. The referenced backtick paths and line numbers must really exist;
4. Anything not "met" must state clearly which piece is missing and what is blocking it.

## Relationship to the §10.7 checklist

and the checking-off is carried by this table + the gate — if any item's evidence path breaks or its status word is written wrong, `tools/verify_plan_traceability.py`
FAILs and names which one.
