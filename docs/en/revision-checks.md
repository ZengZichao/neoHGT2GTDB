# Plan §0.5 review-revision-records check (REV-01…REV-19)

§0.5 is the plan's 19 revisions made on 2026-11-02 against the **local read-only r220 copy**: each records "original assumption →
local measurement → which sections changed as a result". They set the baseline of the entire design, so they too must be checked one by one:
did today's code and documents actually adopt them. The rules match the other registers: status takes `已采纳` / `部分采纳` / `未采纳`; anything that is not
"adopted" must state clearly which piece is missing, and referenced paths and `::符号` must resolve.
