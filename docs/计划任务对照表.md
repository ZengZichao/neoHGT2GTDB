# 计划 §6 任务 ↔ 实现对照表

这份表把方案文档 §6"分阶段实施计划"里**编号化的任务**（S0–S3、2.1–2.13、3.1–3.6、
4.1–4.5，共 28 条）逐条对上实现位置与证据。它存在的理由和 `tools/verify_plan_traceability.py`
一样：散文里写"已完成"没法机器核对，而实际扫出过好几处"计划里写了、代码里没有对应实现"
或"选项能解析但没人读"。

核对规则（由 `python tools/verify_plan_traceability.py --ledger docs/计划任务对照表.md ...`
执行，任一不满足即 FAIL）：

1. §6 表里的每个编号都必须在这张表里出现一次，也不能凭空多出来。
2. 状态只能取 `已实现` / `部分实现` / `未做`。
3. `已实现`/`部分实现` 的实现位置里用反引号写出的文件路径必须**真的存在**。
4. `部分实现`/`未做` 必须在最后一栏写清楚缺的是哪一块（不允许空着含糊过去）。

未编号的阶段条目（P1 的三条任务清单、§6.7 的 P5/P6/P7 散文条目）在文末"未编号条目"一节
交代，不参与编号核对。
