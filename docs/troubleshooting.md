# Troubleshooting

This page collects the errors users are most likely to meet. For command syntax, see [cli-reference.md](cli-reference.md); for configuration, see [config-reference.md](config-reference.md).

## Workspace and environment

### `Refusing to write "...": outside workspace "..."`

`NEOHGT_ROOT` (or `workspace.code_dir` in `config.yml`) is set, and the output path is outside that root. Either move the output inside the workspace or unset `NEOHGT_ROOT` for this run.

### `Refusing to write "...": the GTDB input dataset at "..." is read-only`

The output path is inside the dataset named by `--gtdb-dir`. Choose a different output directory. No configuration changes this rule.

### `No output path given: pass -o/--output explicitly`

An option that expects a path received an empty value, often because an environment variable such as `$NEOHGT_CACHE` was not set. Define the variable or use an explicit path.

### `bad interpreter` or `python3: command not found` after sourcing `tools/env.sh`

`tools/env.sh` uses `python3` from `PATH` unless `NEOHGT_PYTHON` is set. Put the interpreter path in `tools/env.local` or export it before sourcing:

```sh
export NEOHGT_PYTHON=/path/to/conda/envs/neoHGT/bin/python
export NEOHGT_DIAMOND=/path/to/conda/envs/neoHGT/bin/diamond
```

## GTDB data preparation

### `no metadata table ...`

The dataset has taxonomy files but no metadata table. A database build needs `--gtdb-metadata`; `neoHGT gtdb taxdump` can run in `lineage_only` mode without metadata.

### `does not have 7 ranks (provenance check failed)`

A lineage string is truncated or uses a non-standard separator (for example ranks glued with `_`). Use the official `*_taxonomy_rNNN.tsv` file. The error names the file and line.

### `representative ... has no local FASTA`

Metadata marks the accession as a representative, but the local `.faa` file is missing. Add the sequence files, or use `--seq-source gtdb-tar|ena` to generate a fetch plan for manual execution.

### `taxon.map.gz` missing

The build did not finish, or artifacts were moved. Rebuild with `--overwrite`, or restore the file from the same build.

### `db.faa` is missing after a successful build

`--keep-faa drop` was used. That option deletes `db.faa` by design. Rebuild, or use `--keep-faa compress` next time and unpack `db.faa.gz`.

## Probe, taxdump and reconcile

### Self-check count is not 19

`n_checks` is dataset-dependent: each metadata table, taxonomy file and IDlist tier contributes checks. The r220 reference copy reports 19. Read `selfcheck.n_checks` and `selfcheck.status` from the probe JSON.

### `--gtdb-no-selfcheck` is rejected by `probe`

`probe` and `taxdump` use `--no-selfcheck`. `--gtdb-no-selfcheck` belongs to the `database` stage.

### Reconcile exits with status 1

At least one of the five mismatch lists is non-empty. Inspect `missing_faa.tsv`, `extra_faa.tsv`, `nonrep_faa.tsv`, `metadata_not_in_taxonomy.tsv` and `taxonomy_not_in_metadata.tsv` in the `--out` directory.

## Database builds

### `Invalid taxonomic rank: cellular root` from `diamond makedb`

The taxdump came from an NCBI dump with modern rank names that DIAMOND does not accept. Use a taxdump generated by `neoHGT gtdb taxdump` or by `neoHGT database --source gtdb|hybrid`; those write unsupported ranks as `no rank` while keeping the real ranks in the in-memory tree and side tables.

### `makeblastdb` fails or truncates IDs

GTDB sequence IDs are 151–270 characters long, above the 50-character local-ID limit of `makeblastdb`. The GTDB route supports DIAMOND only. `--compile blast` or `both` is rejected unless `--force` is given, and forcing it does not make the route usable.

### Disk-space pre-flight fails

Free space must be at least 3× the estimated `db.faa` size. Free space, choose a smaller tier, or pass `--force` to skip the precheck. Skipping the precheck can leave a partially written library.

### `--complete` is rejected under GTDB

`--complete` uses `ncbi_assembly_level`, which does not describe genome completeness. Use `--min-completeness` and `--max-contamination` instead.

### `--mimag` errors out

The metadata table lacks the MIMAG columns. This is intentional: silently returning the full table would make the option look effective when it is not. Use a release that publishes MIMAG classes, or drop the option.

### `--expand-members` stops before extraction

Member genomes have no local protein files. Provide the official `*_genomic_files_all` tar or use a remote sequence channel to generate a fetch plan.

### A build stops with `No hit is assigned to distal group` during analysis

This is an analysis message, not a build failure: the close group swallowed every best hit. Reduce `--close-size`, or use a reference library that spans more distant taxa.

## Search

### `ambiguous option: --...`

A long-option abbreviation now matches more than one option. Spell out the full long option. See the README's "Incompatible CLI shorthand" for the abbreviations that changed.

### `ERROR: ... lacks the staxids column`

In GTDB mode `--require-staxids` defaults to `yes`. Add `staxids` to the DIAMOND/BLAST output format, or pass `--require-staxids no` to downgrade the error to a warning.

### An 8-column BLAST table is rejected in GTDB mode

The 8-column `outfmt 6` table has no `staxids`, and its `qstart` column would be read as a taxId. Use the 7-column GTDB format: `qseqid sseqid pident evalue bitscore qcovhsp staxids`.

### Every protein appears twice in the search table

`neoHGT search` appends to `<output>/<sample>.tsv`. Use a fresh `-o` directory for each run, or move the previous table aside before rerunning.

### `--taxmap` rejects a `.gz` file

The disk-anchored index needs random byte access. Decompress the mapping first (`gunzip -k taxon.map.gz`) and pass the plain file. It must also be sorted by the first column.

## Analyze

### `No hit is assigned to distal group. Cannot predict HGTs.`

The close group is too large or the library lacks distant taxa. Reduce `--close-size`, use a broader reference library, or inspect the `Close group has N taxa.` line to see how many taxa were actually used.

### `--close-tax` values are dropped with warnings

The supplied taxIds are unreachable in the hit table after the taxonomy tree is pruned to the hits. Check that the close group comes from the same database and that the query has hits in that range. If every supplied taxId is unreachable, `analyze` errors out.

### `donor=0` for many predictions

`donor=0` means the distal LCA is coarser than the requested `--donor-rank`. Loosen `--donor-rank` (for example from genus to family or domain) to annotate more donors.

### `--from-scores` gives a different count from a full run

`--from-scores` reuses a `scores.tsv` written with six significant digits and skips the grouping stage. The prediction set and ranking should match; floating-point columns can differ in the last digit. If the counts differ materially, the `scores.tsv` came from a different input or a different grouping configuration.

## NCBI route

### `ValueError: "___" is not a valid refseq genome category`

Either the category name is wrong (use `viral`, not `virus`) or the NCBI server refused the connection. Test with:

```sh
rsync --list-only --no-motd rsync://ftp.ncbi.nlm.nih.gov/genomes/refseq/
```

### `zcat: can't stat: taxon.map.gz (taxon.map.gz.Z)`

Rename `taxon.map.gz` to `taxon.map.gz.Z`, then rerun the command.

### `diamond` cannot be found

Install DIAMOND (`conda install -c bioconda diamond`) or set `program.diamond` in `config.yml` / `NEOHGT_DIAMOND` in the environment.

### Out of memory during NCBI extraction

Use `--stream-extraction yes` on the NCBI route. It keeps peak memory nearly constant at the cost of extra temporary disk and extraction time. See the GTDB guide's appendix for measured numbers.

## Getting more detail

- `neoHGT <sub-command> --help` lists all options.
- `neoHGT gtdb probe` records the dataset layout, self-check results and input fingerprints.
- `neoHGT gtdb reconcile` records every accession-level mismatch.
- `meta.json` in a built library records the release, layout, counts, DIAMOND version, selection and self-check results.
