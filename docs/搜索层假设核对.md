# 方案 §2.3 搜索层假设核对（S1–S9）

方案 §2.3 逐条列出 `search.py` 在 NCBI 数据形态下做出的**代码级假设**，并对每条写出
"GTDB 后果"。这些结论是可判真伪的：要么今天代码里仍然成立、要么已经被改、要么方案当时的
推断本身就错了。这份登记表把 9 条全部核对一遍，并接受
`tools/verify_plan_traceability.py` 的机器核对（与其余登记表同一套规则）：

1. §2.3 表里的每个编号必须且只能出现一次；
2. 状态只能取 `已按GTDB改造` / `确认无需改动` / `与方案预期不同并已调整` / `未处理`，
   后两类（含"与方案预期不同"）必须写清依据；
3. 引用的路径与 `::符号` 必须真实存在。
