§13 是方案自己的"做到哪一步"视图：每一行写了一周内要交什么、以哪个测试通过为准。把它登记下来
有两个用处：一是让"六个阶段 + 增强项"的完成情况能被机器核对（与其余登记表同一套规则），二是
**把仍未完成的范围写在明面上**，而不是混在正文里。状态取 `已达成` / `部分达成` / `未达成`，
非"已达成"必须写清缺的是哪一块。
